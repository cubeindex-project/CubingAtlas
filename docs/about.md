# About CubingAtlas

CubingAtlas is a community-maintained directory for speedcubers. It brings together useful cubing tools, learning material, communities, databases, and developer resources in one place, so you can spend less time searching and more time cubing.

## What you'll find

The atlas is organised into practical categories, including:

- **Tools** such as timers, trainers, virtual puzzles, solvers, and WCA tools.
- **Resources** for learning, statistics, databases, media, wikis, and communities.
- **Special-interest resources** for hypercubing, non-English-speaking cubers, and cubing software development.
- An archive of **dead projects** that preserves useful historical references.

## Our approach

CubingAtlas is curated, not a ranking or review platform. We aim to make resources easy to discover and describe them clearly enough for visitors to decide whether they are useful. A listing does not imply endorsement by CubingAtlas or the CubeIndex Project.

The directory is never finished: projects launch, move, change ownership, or disappear. Community reports and contributions help keep every page useful and current.

## Open source and community-maintained

CubingAtlas is an open-source project from the [CubeIndex Project](https://github.com/cubeindex-project). Its source and directory content are maintained openly on [GitHub](https://github.com/cubeindex-project/CubingAtlas) and released under the [GNU GPL v3.0](https://github.com/cubeindex-project/CubingAtlas/blob/main/LICENSE).

Want to help improve the atlas? See the [contribution guide](/contribute), report a broken link, or suggest a resource that belongs here.
